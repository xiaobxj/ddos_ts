# 第十四轮：直接预测上涨概率

本轮接续均值收缩诊断，固定输入和骨干结构，用一个分类候选检验训练目标与方向预测目标的匹配程度。模型从相同种子初始化，全部参数重新训练 20 轮；不是固定旧骨干权重的线性探针。

冻结方案见 [protocol.json](protocol.json)。原始收益 >0 才标为上涨；模型输出上行 logit，经 sigmoid 得到概率，三个种子先平均概率，再以严格 >0.5 判断上涨。原收益模型只用于方向对照，不直接转换成概率。

核心实验使用 `D:\ddos_v3\research_v4\.venv_gpu\Scripts\python.exe`。依次运行以下阶段，并等待每一步成功退出：

1. `prepare14.py`：因果训练缓存、原模型及常数参考、旧证据哈希与研究方案冻结。
2. `contract14.py`：原始收益标签、时间边界、初始化、交叉熵梯度、训练更新与诊断隔离检查。
3. `train14.py`：9 个分类模型、180 轮训练、81 次固定状态训练诊断。
4. `score14.py`：所有模型训练完成后，生成 423 条分类概率并复用 423 条原收益预测。
5. `evaluate14.py`：方向与概率指标、年度/种子、固定可靠性分箱、四项预设配对统计。
6. `verify14.py`：模型重放、训练顺序、初始状态、评分和旧证据复核。
7. 使用默认 Python 运行 `figures14.py`、`report14.py`、`delivery14.py --freeze`，制作并封存报告。
