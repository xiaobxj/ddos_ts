双击项目根目录的 **打开每周预测.cmd**，会在浏览器里打开中文界面。也提供没有命令行窗口的 `打开每周预测.vbs` 入口。程序只监听本机地址，沿用现有 Python 环境，无需安装新的包。打开时仅检查状态，不会自动提交预测。

每周五北京时间 **18点后、23点前**，点击 **运行本周流程**，等待结果显示完成。首个候选日是2026-09-18。15点收盘后可以先打开查看，正式记录仍沿用原来的18点门槛。缺少当天完整日线时会提示等待，可以在当晚窗口内再次运行。

界面可以查看五套训练／更新方案和四类方法的上涨概率、52个固定周次的记录状态、已成熟样本的准确率和Brier分数，也可以导出周记录。每格概率是三个种子的平均值；周样本按周计数。尚未成熟时不展示准确率，目标区间涨跌幅不代表交易账户收益。

界面的“涨跌顺序”对应原方法中的 order 特征，来自收盘价涨跌符号的排列关系。原方法名称和计算保持不变。

只在周五运行也可以。尚未成熟的旧标签会在之后的周五继续结算，因此显示结果可能晚于标签实际成熟时间。已到期的季度或年度参数也会在运行时依次检查与更新；年度重训可能较久，界面会显示进度，请等任务完成。

程序调用冻结的第51轮流程，不修改训练配方、前瞻样本安排或已有研究文件。重复提交与逾期回补仍由原流程拦截，整个执行周期继续使用原运行锁。不要同时运行旧命令行的写入命令。

运行完成后点击右上角 **退出程序**。如果直接关闭浏览器标签页，本机服务通常会在最后一次页面访问约两分钟后退出；正在执行的任务会先完成。下次双击会重新打开，记录保持。界面开着时不会定时采集、训练或提交，只会刷新显示状态。重新打开已在运行的程序会复用原服务。

文件位置：

- `prospective_r49`：原始快照、预测、标签与参数注册。
- `prospective_r50/builds`：未来到期的参数构建。
- `prospective_r51/runs`：原运行开始／完成凭据。
- `prospective_app/logs`：界面的任务日志；界面不会清除或重写原账本。
- `prospective_app/startup_error.txt`：启动异常时保存的原因。
